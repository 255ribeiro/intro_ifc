# Instalar o DDS CAD Viewer

No site abaixo, faça login em uma conta da Graphisoft (gratuita). Clique na opção download e siga a instruções para baixar o instalador. Após o download, execute o instalador e siga as instruções.

[https://www.graphisoft.com/plans-and-products/ddscad/viewer](https://www.graphisoft.com/plans-and-products/ddscad/viewer)
