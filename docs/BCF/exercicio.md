# Exercício 01

1. A partir dos arquivos IFC, crie um arquivo BCF orientando a criação de camadas de revestimento como paredes cebola.
2. A clareza na elaboração do arquivo BCF, quanto as vistas e informações registradas faz parte da avaliação.
3. tipos devem ser criados e nomeados para o revestimento:
    1.  externo,
    2.  interno,
    3.  interno para áreas molhadas (banheiros)
4. Para as áreas molhadas, as camadas de revestimento devem ter altura até o forro (2,30 m)
5. As camadas extras devem ter diferentes configurações:
    1. Os tipos deve ter nomes diferentes
    2. Os diferentes materiais devem ter nomes diferentes
    3. as espessuras das camadas devem ser especificadas no arquivo BCF
6. Na exportação para IFC, os revestimentos devem ser classificados como IfcCovering, type Cladding.
7. os arquivos a serem editados devem ser explicitados no arquivo BCF
8. o prazo de uma semana deve ser atribuído para essas mudanças.
9. após a realização das mudanças, os arquivos devem ser exportados novamente para IFC substituindo as versões anteriores.
10. após a verificação das mudanças, os arquivos BCF devem ser marcados como resolvidos (resolved).
11. ao final, todos os arquivos devem ser compactados e enviados em entrega aberta no ambiente virtual da diciplina.
