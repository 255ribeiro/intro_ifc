## 🚀 Como Usar Este Material

### 1️⃣ Para Professores:

1. **Leia primeiro:**
   - `README_Material_Didatico.md` (visão geral)
   - `GUIA_PROFESSOR_BonsaiBIM_3aulas.md` (planejamento detalhado)

   - Baixe arquivo IFC de exemplo
   - **Imprima:** `Guias/GUIA_RAPIDO_Salvar_CSV.md` (1 por aluno)

3. **Distribua aos alunos:**
   - Pasta `Aulas/` completa
   - Pasta `Templates/` completa

4. **Durante as aulas:**
   - Siga o roteiro do guia do professor
   - Use os templates como exemplos
   - Enfatize o problema da vírgula decimal (Aula 3)

- Casos de uso práticos

## ⚠️ ATENÇÃO - Problema da Vírgula Decimal

**Este é o erro #1 dos alunos brasileiros!**

❌ **ERRADO:** `450,00` (vírgula)  
✅ **CORRETO:** `450.00` (ponto)

**Solução:** Veja instruções detalhadas em:
- `Guias/GUIA_RAPIDO_Salvar_CSV.md`
- `AULA3_Quantificacao_BonsaiBIM.md` (seção "Como Salvar CSV")

**Google Sheets (recomendado):**
1. Editar normalmente
2. **ANTES de baixar:** Arquivo → Configurações → Localidade → Estados Unidos
3. Baixar → CSV
4. Verificar no Bloco de Notas
