# Exercício 2

1. Baixe o Blender e o Bonsai BIM
2. Exporte o arquivo IFC com a configuração para BonsaiBIM
3. Crie um arquivo IDS com especificações que se apliquem a cada um dos elementos de revestimento de paredes criados no exercício 1 (uma especificação para cada tipo criado)
4. Teste se o nome do material e a espessura estão de acordo com as especificações definidas no exercício 01
5. Para as camadas de revestimento de áreas molhadas, verifique através do IDS, se a altura corresponde à altura especificada para o forro.
6. ao final, todos os arquivos devem ser compactados e enviados em entrega aberta no ambiente virtual da disciplina
